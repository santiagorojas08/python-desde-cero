# Python desde cero 🐍

Repositorio donde guardo mi aprendizaje de Python, paso a paso. Mi objetivo es convertirme en Ingeniero en Inteligencia Artificial.

## Sobre mí
Soy Santiago, recién graduado de secundaria y próximo estudiante de Ingeniería en IA. Aprendo programando: cada concepto nuevo lo practico con un mini-proyecto.

## Proyectos

| Archivo | Qué hace | Conceptos |
|---|---|---|
| `hola.py` | Saluda al usuario según su edad | `input()`, `int()`, f-strings, `if / elif / else` |

## Cómo ejecutarlos
1. Instala [Python](https://www.python.org/downloads/).
2. Descarga este repositorio.
3. En la terminal, dentro de la carpeta, ejecuta:
   ```
   python hola.py
   ```
